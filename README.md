## MiniCurso:
Este documento serve como um guia simples para compreender e utilizar o GitHub para iniciantes na área de programação, separado em 3 etapas.

É necessário previamente ter:
- Uma conta de email Google ou Microsoft.
- Algum amigo ou colega para testar a parte de colaboração.
- Acesso a internet.

### - Conhecendo-o-GitHub
No início do curso, você compreende melhor o que é o GitHub e aprende de forma prática como criar uma conta.
1. Dúvidas Comuns sobre Git e GitHub.
2. Para que serve uma conta?
3. Como Criar sua primeira conta na prática

### - Criando-o-primeiro-repositorio
Nesta parte do curso, você aprende como criar o seu primeiro repositório e algumas configurações, e alguns comandos git para usar remotamente
1. O que é um repositório?
2. Criando seu primeiro repositório
3. Alguns comandos Git
4. Parte teórica de GitHub remoto

### - Colaborando-e-revisando-alterações
No final do curso, você compreende como adicionar colaboradores no seu repositório, como eles podem modificar o conteúdo dentro do mesmo e vê uma pequena revisão do conteúdo em si
1. Para que serve a colaboração?
2. Como ter colaboradores em seu repositório.
3. Breve Revisão.
