# Capítulo: Trabalhando em Equipe — Adicionando Colaboradores e Acessando Projetos no GitHub

Até agora, você aprendeu o que é um repositório, como fazer commits e gerenciar branches pelo navegador. Mas a verdadeira mágica do GitHub acontece quando você trabalha em grupo! 

Neste capítulo, vamos aprender como convidar outras pessoas para o seu projeto, como o convidado faz para aceitar esse acesso e como gerenciar as permissões diretamente pela interface web do GitHub.

---

## O que é um Colaborador no GitHub?

Um **colaborador** é uma pessoa a quem você concede permissão para modificar diretamente o seu repositório (fazer commits, criar branches e aprovar Pull Requests sem precisar de intermediários complexos). 

* **Nota importante:** Para adicionar um colaborador, o repositório geralmente precisa ser seu (ou você precisa ter permissões de Administrador nele).

---

## Passo a Passo: Como Adicionar um Colaborador pelo Navegador

Siga o roteiro abaixo para convidar sua equipe usando apenas o navegador:

1. **Acesse a página principal do seu Repositório**
   * *Subtítulo:* Certifique-se de que você está logado na sua conta
   * Abra o GitHub no navegador, entre no seu repositório e olhe para o menu horizontal logo acima dos arquivos do projeto.

2. **Entre nas Configurações (Settings)**
   * *Subtítulo:* Disponível apenas para os donos ou administradores do repositório
   * No canto superior direito das abas do repositório, clique na aba **Settings** (com o ícone de uma engrenagem).

3. **Navegue até a seção de Colaboradores**
   * *Subtítulo:* Localizado no menu lateral esquerdo
   * Na barra lateral esquerda da página de configurações, procure pelo grupo **Access** e clique em **Collaborators**.

4. **Adicione o novo membro**
   * *Subtítulo:* Tenha em mãos o nome de usuário ou e-mail do GitHub do colega
   * Clique no botão verde/azul **"Add people"** (ou "Add collaborator"), digite o nome de usuário do GitHub do seu colega na barra de pesquisa e selecione-o na lista que aparecer.

5. **Confirme o convite**
   * *Subtítulo:* Seu colega receberá um link de acesso
   * Clique em **"Add [Nome do Usuário] to this repository"**. O GitHub enviará um convite pendente. Assim que seu colega aceitar o convite (por e-mail ou acessando o link do repositório), ele estará pronto para colaborar!

## Do Outro Lado: Como o Convidado Acessa o Projeto?

Assim que o administrador envia o convite, o colega convidado precisa aceitá-lo para desbloquear as permissões de edição. Há duas maneiras principais de fazer isso pelo navegador:

1. **Pelo E-mail de Notificação:** 
   * Se o usuário tiver um e-mail válido vinculado à sua conta do GitHub, ele receberá uma mensagem automática na caixa de entrada contendo um botão direto como **"View Invitation"** (Ver convite). Clicar nele abrirá a página do repositório no navegador já com a opção de aceite.
2. **Acessando o Link Direto do Repositório:** 
   * Se o dono do projeto enviar o link direto do repositório (ex: `https://github.com/usuario/nome-do-projeto`) via chat ou WhatsApp, o colega (estando logado em sua própria conta do GitHub) deve abrir esse link no navegador. 
   * Imediatamente, aparecerá uma barra de destaque no topo da página informando: *"You have been invited to collaborate on this repository"* (Você foi convidado para colaborar neste repositório), acompanhada de um botão verde **"Accept invitation"**.
3. **Após Aceitar:**
   * Uma vez clicado em aceitar, a página é atualizada e o usuário ganha acesso total de gravação (poderá editar arquivos, criar branches e abrir Pull Requests diretamente pela interface web).
